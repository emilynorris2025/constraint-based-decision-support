# Data

This folder is reserved for structured input data used by the decision support model.

Depending on future development, data may include:

* Participant information
* Group affiliations
* Relationship preferences
* Conflict relationships
* Table capacities
* Scenario-specific requirements

The current version of the project may define this information directly within the MiniZinc model.

A future enhancement would separate the model logic from the input data using MiniZinc `.dzn` data files.
